## 1. Technological Uncertainty

Block 7 requires a paired comparison between PSG and wearable EEG without changing participants, labels, temporal support, or event evaluation. It was uncertain whether one fixed PSG configuration could cover all 128 recordings because the dataset contains different optional EOG, respiratory, pulse, oxygen-saturation, and headband motion configurations.

If the full PSG comparator used every available sensor, channel availability would change the cohort and the feature method would mix physiologically different signal types. If only a frontal PSG pair were used, the analysis would lose the intended full-versus-reduced PSG contrast. This compatibility question had to be resolved before feature extraction or fitting.

## 2. Predeclared Method

The paired-transfer protocol and channel-audit plan were committed as `1f6797f` before the audit implementation or result. They defined:

- `PSG-6`: `PSG_F3/F4/C3/C4/O1/O2` as the complete common PSG EEG montage;
- `PSG-2`: `PSG_F3/F4` as the reduced PSG pair;
- `HB-2`: `HB_1/HB_2` as the real wearable input;
- the fixed eight-epoch DE-B log-bandpower logistic method;
- strict zero-shot transfer before target-derived feature alignment;
- a validation-only gate for one robust location/scale alignment method;
- no adversarial adaptation, supervised fine-tuning, feature selection, or model search;
- one frozen descriptive use of the existing test partition after all configurations are fixed; and
- a requirement for new locked or external evidence for later confirmation.

The `F3/F4` to `HB_1/HB_2` mapping preserves left/right order and feature dimension. Because the electrode locations are different, the comparison estimates combined electrode-location and device shift rather than hardware shift alone.

## 3. Audit Implementation

The audit implementation was committed as `d73a278` before execution. It read all 256 EDF headers and their 256 channel sidecars and checked every pair for:

- file completeness;
- exact header-to-sidecar channel name and order agreement;
- required EEG channel presence, units, and sampling frequency;
- matching M1 reference;
- matching PSG/headband duration; and
- eligibility for all three fixed input sets.

The retained output also inventories optional-channel availability and each distinct channel configuration. No signal samples, labels, features, model scores, validation metrics, or test artifacts were used.

## 6. Interpretation and Decision

The channel gate passed without excluding any recording. `PSG-6` is retained as the full common PSG EEG comparator, `PSG-2` isolates channel reduction within the PSG acquisition, and `HB-2` measures the additional real acquisition shift.

The heterogeneous optional sensors are a documented reason not to call an all-sensor model the complete-cohort baseline. Their exclusion is determined by availability and method compatibility, not by model performance.
