# Weekly Technical Record: 2026-10-12 to 2026-10-18

## 1. Technical uncertainty

The existing direct model used signal after each candidate boundary and was therefore retrospective. It remained uncertain whether a strictly past-only wearable model could detect REM/Wake boundaries and whether combining REM-to-Wake with Wake-to-REM positives would improve the rare-event signal.

## 2. Pre-result work

- Froze a causal decision at `nominal + 15 s` using eight 30-second windows ending at the decision time.
- Defined `CAUSAL-RW` and `CAUSAL-BI` with identical negatives, participant folds, features, solver, and alarm budget.
- Separated transition detection from an oracle-event direction diagnostic.
- Audited 150,967 supported causal decisions and 146,987 shared negatives.
- Excluded transition 406 before fitting because a feature-grid gap prevented eight contiguous past windows.

The final supported event cohort contained 180 REM-to-Wake and 61 Wake-to-REM events.

## 3. Work performed

- Completed 50 participant-grouped nested Stage A fits and five outer out-of-fold Stage B fits.
- Selected each Stage A threshold from inner out-of-fold scores under the fixed 0.25 false-alarms/hour budget.
- Evaluated full-night causal alarms from 629.0292 supported hours.
- Recorded participant-level results and a 2,000-resample paired comparison.
- Ran the independent read-only validator twice and verified 57 external artifacts.

## 4. Result

For REM-to-Wake detection, `CAUSAL-RW` reached F1 0.0517 and `CAUSAL-BI` reached F1 0.0387. The -0.0130 F1 difference failed the required +0.03 gate. Neither detector matched a Wake-to-REM event.

At known event checkpoints, the separate direction classifier reached macro F1 0.8290 and balanced accuracy 0.8272, with REM-to-Wake recall 0.9167 and Wake-to-REM recall 0.7377.

## 5. Failure mode and interpretation

The numerical controls passed, so the weak detection result is not explained by the prior saturated-solver failure. Adding Wake-to-REM positives did not provide a shared boundary signal that improved full-night causal localization.

The Stage B result is a positive mechanism finding: the preceding wearable signal contains direction information once a transition checkpoint is supplied. The unresolved limitation is finding the rare checkpoint among full-night background candidates.

Stage A thresholds varied by several orders of magnitude across participant folds, indicating calibration instability despite finite, non-saturated scores. Stage B may partly distinguish recent REM from Wake occupancy rather than a unique transition waveform, so its mechanism requires a separate test before stronger interpretation.

## 6. Decision

Stop the bidirectional detection target at v0.1. Do not tune timing, class weights, thresholds, or losses on these outer results. Keep validation and current test closed. Any later causal detector study requires a separately frozen protocol and new confirmation boundary.
