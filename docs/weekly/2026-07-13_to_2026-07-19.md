### 2026-07-15

#### Integrated signal-quality decisions v0.2

**Hypothesis:** Structural checks and raw amplitude/continuity evidence can be combined into one deterministic decision per reviewed window without treating the nonspecific 10-MAD outcome as an exclusion.

**Method:** Added `docs/labels/signal_quality_flag_spec_v0.2.md` and `scripts/build_signal_quality_flags_v0_2.py`. The script joins all 476 transition and 4,302 background rows one-to-one with the July 11 amplitude assessment. It preserves four outcomes: clean include, include with 10-MAD sensitivity flag, targeted review, and critical exclusion.

**Result:** The integrated artifact contains 76 clean, 201 10-MAD sensitivity, 73 targeted-review, and 15 critically excluded primary REM-to-Wake windows. It contains 23 clean, 69 10-MAD sensitivity, 19 targeted-review, and zero critically excluded secondary Wake-to-REM windows. Background decisions are 2,702 clean, 1,291 10-MAD sensitivity, 289 targeted-review, and 20 critical exclusions. The retained primary set remains 350 events across 88 `pid` groups.

**Limitation:** Targeted-review windows have not yet been visually adjudicated, and their inclusion in the primary versus sensitivity analysis is not frozen.

**Decision:** Use `labels/signal_quality_flags_v0.2/` for split and preprocessing work. Retain v0.1 as the structural-only historical artifact.

#### Deterministic participant-grouped split v0.1

**Hypothesis:** A fixed 64/16/20 `pid` assignment can preserve participant independence while maintaining adequate primary-event and quality-history representation in all partitions.

**Method:** Predeclared `docs/splits/grouped_pid_split_spec_v0.1.md`, then ran `scripts/build_grouped_pid_split_v0_1.py`. The deterministic search used NumPy PCG64 seed `20260715`, evaluated 50,000 exact-size candidate assignments, and used only participant metadata and pre-model label/quality counts. Raw signal features, predictions, and performance results were not used.

**Result:** The selected split contains 64/16/20 `pid` values and 82/20/26 recordings in train/validation/test. Retained primary event counts are 229/51/70; positive-`pid` counts are 56/14/18. Retained secondary counts are 75/16/20 and background review counts are 2,761/651/870. Every partition contains repeated participants, both recorded sex categories, background-only participants, and participants with critical-exclusion history. No `pid` crosses partitions.

**Limitation:** Validation contains fewer targeted background-review flags than its proportional target, and targeted-review inclusion remains a later sensitivity decision. The split balances observed BOAS counts but cannot guarantee balance in unmeasured clinical factors.

**Decision:** Freeze `splits/grouped_pid_split_v0.1/` for the first baseline comparisons. The test partition is locked and cannot guide preprocessing, threshold selection, model selection, or error-driven revision.

#### Minimal preprocessing v0.1: failed full-window coverage check

**Hypothesis:** Continuous 0.3-35 Hz filtering, 256-to-128 Hz resampling, and train-only robust scaling can process every retained train window with exact sample geometry.

**Method:** Predeclared `docs/preprocessing/minimal_wearable_eeg_preprocessing_spec_v0.1.md`, then ran `scripts/validate_minimal_preprocessing_v0_1.py` on all 82 train recordings. The script filtered complete recordings before extracting windows, fitted channel-specific robust scaling from a deterministic 1 Hz train sample, and did not open validation or test EDFs.

**Result:** All 82 recording checks and all three synthetic frequency checks passed. However, only 3,063 of 3,065 retained windows passed. `T0120` returned 54,016 rather than 61,440 input samples, and `T0196` returned 44,032. Both were REM-to-Wake windows near recording ends.

**Failed approach:** Structural quality v0.1 had checked that PSG and headband window lengths agreed, but did not check that both lengths equalled the required 240 seconds. Equal device lengths were therefore incorrectly interpreted as complete coverage.

**Decision:** Fail preprocessing v0.1 and preserve the two failed rows. Do not pad or redefine them after observing the result.

#### Coverage-aware signal quality v0.3

**Method:** Added `docs/labels/signal_quality_flag_spec_v0.3.md` and `scripts/build_signal_quality_flags_v0_3.py`. The new critical rule requires exactly 61,440 input samples for every 240-second window.

**Result:** Eight primary transition windows have incomplete coverage. Six were already critically excluded by amplitude/flatline evidence; `T0120` and `T0196` are newly excluded. The retained primary set decreases from 350 to 348 events while all 88 contributing `pid` groups remain represented.

**Decision:** Use quality v0.3 for preprocessing and later input construction. Keep the frozen participant assignment unchanged because the new failures were discovered after train-signal inspection.

#### Minimal preprocessing v0.2: resolved mechanical failure

**Method:** Reran the unchanged filtering, resampling, and train-only scaling pipeline using quality v0.3. The initial rerun stopped before EDF access because a versioned input filename remained hardcoded to v0.2; the filename construction was corrected and the full run repeated.

**Result:** All 82 train recordings, all 3,063 retained train windows, and all three synthetic frequency checks passed. Synthetic RMS gains were 0.000003 at 0.05 Hz, 1.000310 at 10 Hz, and 0.029931 at 50 Hz. Train robust scales were 12.815094 uV for `HB_1` and 13.943297 uV for `HB_2`. Validation and test recordings read remained zero.

**Limitation:** Passing these checks establishes mechanical reproducibility, not that the filter or scaling improves transition detection. The zero-phase filter is noncausal and cannot be assumed valid for a future streaming implementation.

**Decision:** Accept preprocessing v0.2 as the current minimal offline pipeline. Model training remains blocked until targeted-review treatment and the label/preprocessing gate are frozen.

### 2026-07-18

#### Targeted-review analysis membership v0.1

**Uncertainty:** The targeted amplitude, abrupt-jump, and repeated-endpoint flags identify possible artifacts but are not validated unusable-signal labels. Including all flagged windows in the primary analysis could admit unresolved artifacts, while removing them entirely could discard plausible physiology and participant groups.

**Method:** Predeclared `docs/labels/quality_analysis_membership_spec_v0.1.md`, then ran `scripts/build_quality_analysis_membership_v0_1.py` using quality v0.3 and the frozen split only. No EDF was opened. Clean and 10-MAD-only rows are primary eligible, targeted-review rows are expanded quality-sensitivity only, and critical rows are excluded from both.

**Result:** All 476 transition and 4,302 background review rows were preserved with complete split membership and zero participant leakage. The primary REM-to-Wake set contains 276 events across 72 `pid` groups: 180/37/59 events across 47/10/15 positive groups in train/validation/test. The expanded set contains 348 events across 88 groups: 227/51/70 events across 56/14/18 groups. Sixteen groups have primary events only in the targeted tier, distributed 9/4/3 across the partitions. The primary background review pool contains 3,993 rows; the expanded pool contains 4,282. A second full build reproduced identical SHA-256 hashes for all seven output files.

**Limitation:** The conservative primary validation set contains only 37 events across 10 positive groups. This limits metric precision and must be visible in later participant-level reporting.

**Decision:** Use the conservative membership for the first baseline and the expanded membership as a prespecified quality-sensitivity comparison. Do not revise the tiers using later model performance.

#### Frozen-artifact integrity audit v0.1

**Uncertainty:** Separate label, quality, split, membership, and preprocessing steps could preserve plausible aggregate counts while silently losing, duplicating, or changing individual rows.

**Method:** Predeclared `docs/feasibility/block4_artifact_integrity_protocol_v0.1.md`, then ran `scripts/audit_block4_artifact_integrity_v0_1.py`. The audit compared IDs, participant fields, sample windows, quality decisions, membership tiers, and partitions across the frozen artifacts. It independently rebuilt the expected noncritical v0.3 train-window set and compared it one-to-one with preprocessing v0.2. No raw signal file was opened.

**Result:** All 71 checks passed. The audit linked 476 transition rows and 4,302 background rows through their source, quality, and membership tables. All 3,063 expected noncritical train windows and all 82 train recordings matched preprocessing exactly; no validation/test or critical-exclusion row was present. A manifest records relative paths, row counts, file sizes, and LF-normalized SHA-256 hashes for 19 frozen files. A second run reproduced all three audit outputs byte-for-byte.

**Decision:** Retain the July 18 gate pass. Aggregate-count agreement is no longer the only integrity evidence; later work can verify the exact frozen files against the manifest.
