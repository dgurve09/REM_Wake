## 1. Technological Uncertainty

The Block 7 channel audit established that all recordings contain the fixed `PSG-6`, `PSG-2`, and `HB-2` channels, but it did not establish that their feature paths are mechanically comparable. Separate normalization, epoch-retention, spectral, or feature-order behavior could create an apparent PSG-to-wearable difference unrelated to the research question.

The feature gate therefore tested whether the frozen three-path implementation preserves common timing and schema, produces identical overlapping PSG features, and reproduces the earlier wearable feature construction before any transfer model is fitted.

## 2. Method

The implementation was committed on August 31 and executed on September 6 under the previously committed feature-validation plan. It:

- reconstructed 82 train recordings across 64 `pid` groups from the frozen split;
- read only train PSG/headband signals;
- applied the fixed 0.3-35 Hz filter, 256-to-128 Hz resampling, and Welch log-bandpower method;
- fitted six PSG and two wearable robust channel scalers using deterministic 1 Hz train samples;
- reused the six-channel PSG `F3/F4` scaler parameters for the reduced PSG path;
- generated `PSG-6`, `PSG-2`, and `HB-2` base features and eight-epoch context centers;
- compared overlapping PSG paths at tolerance `1e-10` and the wearable path with the frozen reference at tolerance `1e-6`; and
- wrote full feature arrays outside Git while retaining compact checks and SHA-256 manifests.

An independent read-only validator was committed before use. It did not read raw EDF files. It reconstructed train membership, rejected non-train rows, checked exact ordered schemas, rehashed and reopened every stored artifact, and recomputed the cross-path controls.

## 6. Transfer Validation Method

Before validation feature access, an execution plan fixed common temporal support, PSG scaling for the zero-shot wearable path, pooled-MAD gate arithmetic, threshold inheritance, and the conditional-alignment action. The run then:

- generated 82 train zero-shot feature arrays and 80 validation arrays outside Git;
- fitted `P6-D`, `P2-D`, and `H2-D` on the same 180 positive and 2,563 background train candidates;
- retained all 657 validation labeled candidates for every direct input;
- scored all supported validation boundaries;
- selected one threshold per direct comparator by the frozen event rule;
- applied the unchanged `P2-D` model and threshold to `HB-2` PSG-scaled features for strict zero-shot transfer; and
- computed the 80-dimension paired train-distribution gate before deciding whether alignment was authorized.

## 7. Transfer Validation Result

| Comparator | Threshold | Precision | Recall | Event F1 | False alarms/hour |
|---|---:|---:|---:|---:|---:|
| `P6-D` | 0.99 | 0.0969 | 0.5135 | 0.1631 | 1.1107 |

`P6-D - P2-D` event F1 was -0.0256 with paired 95% interval -0.1164 to +0.0808, while its false-alarm difference was +0.7405/hour with interval +0.2402 to +1.4109. Adding four PSG channels did not support H7.1 on validation.

Strict zero-shot F1 was 0.1202 lower than direct `P2-D`; the paired direct-minus-zero-shot interval was +0.0336 to +0.2001. Zero-shot false alarms were 0.2824/hour higher than `P2-D`, but the paired interval -0.0506 to +0.7972 for zero-shot minus direct crossed zero. Relative to `H2-D`, zero-shot transfer had lower F1 and 0.8032 fewer false alarms/hour, so the comparison is a recall/alarm tradeoff rather than uniform degradation.

The adaptation performance condition opened because zero-shot F1 was 0.0438 below `H2-D`. The distribution condition closed because 11/80 dimensions, or 13.75%, exceeded 0.50 pooled robust scale units, below the required 20%. `P2-H2-A` was therefore skipped exactly as predeclared.

`P6-D - P2-D` test F1 was +0.0620 with paired 95% interval +0.0019 to +0.1194, reversing the validation point direction. Its false-alarm difference was +0.0955/hour with an interval crossing zero. The apparent effect of the four additional PSG channels is therefore not stable across the used validation and test participants.

`P2-D - P2-H2-Z` test F1 was +0.0362, in the same direction as validation but with paired interval -0.0434 to +0.1001. The false-alarm interval also crossed zero. The large validation F1 loss under strict transfer did not reproduce with comparable certainty in this descriptive cohort.

Relative to `H2-D`, zero-shot transfer again had lower F1 and fewer false alarms. The F1 difference was -0.0426 with an interval crossing zero; the false-alarm difference was -0.8448/hour with interval -1.2441 to -0.5081. This supports a threshold/calibration tradeoff, not uniform zero-shot degradation.

The fixed quality sensitivity retained `P6-D` as the highest-F1 comparator and `P2-H2-Z` as the lowest. It changed the close `P2-D`/`H2-D` F1 ordering, reinforcing the conclusion that those point estimates are not robustly separated.
