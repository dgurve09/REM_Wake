# Weekly Technical Record: 2026-10-19 to 2026-10-25

## 1. Technical uncertainty

The prior causal models showed measurable REM and Wake state information but weak event localization. The endpoint-factorized score also produced multi-hour above-threshold runs. It remained uncertain whether strictly causal 15-second dynamics and inter-channel change features could improve localization under a peak-first alarm representation.

## 2. Hypothesis and controls

Before implementation, a train-only protocol fixed two candidates, 260 total feature definitions, natural-prevalence logistic fitting, five participant folds, a 60-second peak refractory interval, a 0.25 false-alarms/hour budget, and a `+0.03` F1 advancement gate. Validation and current test remained closed.

The pre-result audit covered 82 recordings, 64 participant groups, 150,967 causal decision points, 180 target-positive rows, and zero seconds of future signal. All 13 controls passed.

## 3. Work performed

- Extracted 180 new spectral, aperiodic-proxy, entropy, amplitude, Hjorth, coupling, and change values from raw two-channel BOAS EEG.
- Preserved the existing 80 causal band-power context values as the matched baseline.
- Completed 50 participant-grouped nested fits and fold-local threshold selections.
- Replaced threshold-first run collapse with a fixed local-maximum and refractory procedure defined before results.
- Reconstructed thresholds, alarms, metrics, participant tables, bootstrap intervals, and decisions independently.
- Audited the adjacent ten-dataset hypnogram collection and separated wearable, PSG-mechanism, and label-uncertainty roles.
- Audited 196 common-channel PSG nights across BOAS, gx36m, and ISRUC group 3 and froze a dataset-held-out protocol before feature extraction.
- Generated 120 baseline and 324 advanced causal features on 378,054 decision points at each dataset's native sampling rate.
- Completed 36 fixed leave-one-dataset-out and inner-fold model fits, then independently reconstructed the external results.

## 4. Failure and correction

The first model invocation stopped before fitting because the reviewed feature summary recorded whether the cache was written or reused during that invocation. The scientific artifacts were unchanged, but the audit table was not reproducible. The field was changed to stable artifact provenance, the 13-control pre-result audit reproduced, and only then was fitting started.

## 5. Result

`BASE-PEAK` reached precision 0.0252, recall 0.0222, F1 0.0236, and 0.2464 false alarms/hour. `ADV-PEAK` reached precision 0.1286, recall 0.1000, F1 0.1125, and 0.1940 false alarms/hour.

The F1 difference was `+0.0889`; its participant-bootstrap 95% interval was `+0.0433` to `+0.1393`. The false-alarm difference was `-0.0525/hour`, with interval `-0.2216` to `+0.0949/hour`. The predeclared point gate passed, all 50 fits converged, and alarm counts were monotonic across inner thresholds.

## 6. Interpretation

The advanced causal descriptors added signal beyond the older band-power context. The result does not establish reliable detection: only 18/180 events were detected, only 15/64 participant groups had a true positive, and F1 remained 0.1125. Peak-first mapping alone did not rescue the old features because `BASE-PEAK` underperformed the earlier contiguous-run causal comparator.

The candidate is frozen for new-cohort confirmation. No post-result feature, threshold, tolerance, or refractory tuning is authorized on the current outer results.

## 7. Other datasets

The local 2,381-row, ten-dataset hypnogram corpus remains assigned to transition prevalence, scorer disagreement, and repeated-night variability. Raw PSG from BOAS, gx36m, and ISRUC group 3 supplied 196 compatible F4/C4/O2 nights for a separate mechanism-portability experiment. The remaining label-only datasets were not counted as EEG samples. None of these external sources can confirm wearable performance because they do not contain a compatible simultaneously recorded wearable channel set.

## 8. Verification and next work

The causal multiscale validator passed 13/13 checks twice and verified 134 external artifact hashes. A complete second execution reproduced every reviewed result and external artifact.

The subsequent PSG feature audit passed 11/11 pre-fit checks. The held-out experiment completed 36/36 converged fits and passed 12/12 run controls. Its independent validator passed 13/13 checks twice and verified 42 model and score artifacts.

## 9. Multi-dataset PSG result

The pooled primary external evaluation contained 68 gx36m/ISRUC nights, 30 participant groups, and 156 events. `PSD3-BASE` reached F1 0.1938, recall 0.1987, and 0.2318 false alarms/hour. `ADV3-CHANGE` reached F1 0.2390, recall 0.2436, and 0.2161 false alarms/hour.

The advanced-minus-baseline F1 difference was `+0.0452`; its stratified participant-bootstrap 95% interval was `-0.0208` to `+0.1035`. The recall-difference interval was `-0.0390` to `+0.1222`, and the false-alarm-difference interval was `-0.0672` to `+0.0358/hour`. The frozen point gate passed, but the improvement was not participant-supported across its full interval.

The dataset results were heterogeneous. gx36m improved from F1 0.1812 to 0.1992. ISRUC improved from 0.2727 to 0.4211, but contained only ten participants and 32 events. The descriptive BOAS holdout remained effectively unchanged. gx36m expert 2 labels also reversed the advanced direction, so scorer uncertainty remains material.

## 10. Multi-dataset failure and correction

The first eligibility audit rejected one gx36m recording because 166 seconds of EEG followed its last scored epoch. The rule was corrected to exclude the unscored tail while retaining the fully supported scored region.

Before feature generation, symmetric resampling was removed because it could mix later samples into earlier causal decisions. All recordings instead retained their native sampling rates and used forward-only filtering.

The first result-validator run expected every feature-grid row to be scored. ISRUC consensus-unknown epochs are intentionally excluded, giving 750,636 score rows across both candidates instead of 756,108. Only the audit expectation changed; model, score, alarm, and metric artifacts were unchanged.

## 11. Decision and next work

The external point result is sufficient to retain the advanced PSG mechanism for a separately predeclared paired wearable-transfer test. It is not a reliable detector: the advanced model found only 38/156 external events, missed 118, and its improvement interval included zero.

Do not tune features, labels, model settings, thresholds, refractory interval, or event tolerance against these held-out results. Next, complete the all-hypnogram transition and annotation-uncertainty analysis. Before any wearable transfer, freeze the mapping from F4/C4/O2 features to available paired PSG/headband channels and define a new participant-grouped evaluation. Do not describe this PSG evidence as wearable or clinical validation.
