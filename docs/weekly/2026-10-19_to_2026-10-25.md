# Weekly Technical Record: 2026-10-19 to 2026-10-25

## 1. Technical uncertainty

The prior causal models showed measurable REM and Wake state information but weak event localization. The endpoint-factorized score also produced multi-hour above-threshold runs. It remained uncertain whether strictly causal 15-second dynamics and inter-channel change features could improve localization under a peak-first alarm representation.

## 2. Hypothesis and controls

Before implementation, a train-only protocol fixed two candidates, 260 total feature definitions, natural-prevalence logistic fitting, five participant folds, a 60-second peak refractory interval, a 0.25 false-alarms/hour budget, and a `+0.03` F1 advancement gate. Validation and current test remained closed.

The pre-result audit covered 82 recordings, 64 participant groups, 150,967 causal decision points, 180 target-positive rows, and zero seconds of future signal. All 13 controls passed.

## 4. Failure and correction

The first model invocation stopped before fitting because the reviewed feature summary recorded whether the cache was written or reused during that invocation. The scientific artifacts were unchanged, but the audit table was not reproducible. The field was changed to stable artifact provenance, the 13-control pre-result audit reproduced, and only then was fitting started.

## 5. Result

`BASE-PEAK` reached precision 0.0252, recall 0.0222, F1 0.0236, and 0.2464 false alarms/hour. `ADV-PEAK` reached precision 0.1286, recall 0.1000, F1 0.1125, and 0.1940 false alarms/hour.

The F1 difference was `+0.0889`; its participant-bootstrap 95% interval was `+0.0433` to `+0.1393`. The false-alarm difference was `-0.0525/hour`, with interval `-0.2216` to `+0.0949/hour`. The predeclared point gate passed, all 50 fits converged, and alarm counts were monotonic across inner thresholds.

## 6. Interpretation

The advanced causal descriptors added signal beyond the older band-power context. The result does not establish reliable detection: only 18/180 events were detected, only 15/64 participant groups had a true positive, and F1 remained 0.1125. Peak-first mapping alone did not rescue the old features because `BASE-PEAK` underperformed the earlier contiguous-run causal comparator.

The candidate is frozen for new-cohort confirmation. No post-result feature, threshold, tolerance, or refractory tuning is authorized on the current outer results.
