## 2. Technological Uncertainty

Sleep staging from wearable EEG is established, but it was uncertain whether ordinary stage classification followed by deterministic REM-to-Wake transition derivation could provide an adequate event-level comparator under the project's participant split, quality tiers, and 30-second boundary uncertainty.

The test was necessary because epoch-level stage metrics cannot establish event precision, recall, false alarms per hour, or boundary timing. The direct detector should later be compared against measured stage-first behavior rather than against an assumed weak baseline.

## 3. Protocol and Matching

**Method:** `docs/evaluation/stage_first_baseline_protocol_v0.1.md` was frozen before model results were inspected. It defined SF-A fixed BOAS headband `stage_ai`, SF-B epoch-only multinomial logistic regression, and SF-C five-epoch-context logistic regression. It also fixed the participant split, preprocessing v0.2, two-channel spectral features, quality memberships, event derivation, +/-15-second primary tolerance, +/-45-second sensitivity tolerance, and participant-cluster bootstrap.

**Validation:** `scripts/validate_stage_first_event_matching_v0_1.py` tested the one-to-one matcher on 10 synthetic cases. All passed, including exact and edge matches, outside-tolerance errors, duplicate predictions, ignored-quality references, eligible-reference precedence, empty inputs, minimum-error tie-breaking, and cross-recording isolation.

**Decision:** Use the matcher unchanged for all three stage-first comparators. Quality-excluded references remain ignore zones only after eligible references are matched.

## 4. Fixed BOAS Comparator SF-A

**Hypothesis:** Dataset-provided headband `stage_ai` would recover some REM-to-Wake events but could not be treated as ground truth or as a fully independent model because its training provenance is not established in the local dataset documentation.

**Method:** `scripts/run_stage_first_fixed_comparator_v0_1.py` aligned the PSG and headband event tables for all 128 recordings, compared `stage_ai` with PSG `stage_hum`, derived adjacent 4-to-0 transitions, and applied the frozen event evaluation.

**Implementation failure:** The first execution stopped before writing metrics because the output wrapper attempted to add a `tolerance_sec` column already returned by the evaluator. A duplicate-column guard was added without changing any scientific configuration, and the run was repeated. This was a routine implementation error, not evidence about the hypothesis.

**Result:** All 128 event-table pairs passed alignment. Test stage macro F1 was 0.7248. At the primary +/-15-second tolerance, test event precision was 0.3333, recall 0.4237, F1 0.3731, and false alarms were 0.2609/hour. At +/-45 seconds, test event F1 increased to 0.5113.

**Limitation:** SF-A is descriptive because its provenance and independence from BOAS are not established. Its relatively strong result cannot be interpreted as an independently trained participant-held-out estimate.

## 5. Transparent Feature Baselines SF-B and SF-C

**Hypotheses:** A transparent two-channel spectral model would establish a reproducible lower-complexity comparator, and five-epoch temporal context would improve stage or event performance over epoch-only features.

**Method:** `scripts/run_stage_first_feature_baseline_v0_1.py` applied frozen continuous 0.3-35 Hz filtering, 256-to-128 Hz resampling, and train-derived robust channel scaling. Each channel contributed delta, theta, alpha, sigma, and beta log mean Welch power. SF-B used the current 30-second epoch; SF-C concatenated two previous, current, and two following epochs. Both used balanced multinomial logistic regression with the frozen settings and no hyperparameter search.

**Train/validation result:** SF-B validation macro F1 was 0.4460 and primary event F1 was 0.0204. SF-C improved validation macro F1 to 0.4969 and event F1 to 0.0510, but produced 345 false positives and 2.1597 false alarms/hour. SF-B converged at 316 iterations. SF-C reached the frozen 500-iteration ceiling and emitted one convergence warning; the failed convergence condition was retained.

**Test lock:** The validation result and decision were written before test signal access. The pre-test check found zero cached test features and no test metric file. Both frozen models were then evaluated once without refitting or configuration changes.

**Frozen test result:** SF-C improved over SF-B in stage macro F1, 0.4979 versus 0.4382, and primary event F1, 0.0766 versus 0.0337. SF-C produced 18 true positives, 393 false positives, and 41 false negatives for 59 primary reference events. Precision was 0.0438, recall 0.3051, and false alarms were 1.9692/hour. The participant-cluster bootstrap 95% interval for SF-C event F1 was 0.0390 to 0.1183.

**Sensitivity:** Increasing tolerance to +/-45 seconds raised SF-C test recall to 0.4237 and event F1 to 0.1066, but false alarms remained 1.9291/hour. Timing uncertainty therefore explains only part of the failure.

**Comparison caveat:** Valid prediction coverage differs by comparator. SF-A, SF-B, and SF-C provide 191.625, 200.975, and 199.575 supported test hours, respectively. The closeout therefore reports comparator-specific exposure and does not treat SF-A as an identical-coverage independent ranking.

## 6. Interpretation and Decision

Temporal context helped consistently, supporting H5.3 for both validation stage macro F1 and event F1. However, the transparent stage-first method remains unsuitable as a practical event alarm because independent 30-second stage decisions generate too many 4-to-0 boundaries. Useful stage classification does not imply useful boundary detection.

### Exploratory failure-mechanism analysis

**Status:** This diagnostic was planned after the primary results were known and is explanatory rather than confirmatory. It used saved result tables only and did not open raw signals, external features, or fitted models.

**Reference-side result:** At the 59 primary SF-C test boundaries, the preceding REM endpoint was predicted correctly 22 times and the following Wake endpoint 46 times. Of the 41 missed events, 28 missed only the preceding REM endpoint, four missed only the following Wake endpoint, and nine missed both. No primary test reference lacked context prediction coverage.

**False-positive result:** Of 393 SF-C test false positives, 158 occurred at a human other-to-Wake pair, 148 at a human REM-to-other pair, 66 without a human stage change, and 21 at another transition. All 20 test participants produced false positives; the highest-FP 20% contributed 45.04%, so the failure is broad with moderate concentration rather than isolated to one participant.

**Fragmentation result:** Across matched supported epochs, SF-C produced 4,311 all-stage transitions versus 1,979 in the human sequence, a 2.1784-fold rate. It produced 799 REM bouts versus 156 human bouts. Median predicted REM-bout duration was 60 seconds versus 600 seconds for the human sequence. The transition-rate excess was also present in train and validation, at 2.2607-fold and 1.8902-fold.

**Interpretation:** The dominant failure is sequence fragmentation. The model both loses REM before true boundaries and creates many short predicted REM runs, providing excessive opportunities for spurious 4-to-0 transitions. This finding does not change the frozen primary score or authorize a post-test model adjustment.

### Exploratory context-effect diagnostics

**Questions:** Determine whether SF-C's aggregate improvement over SF-B is consistent by participant, whether the additional +/-45-second matches are early or late, and whether fragmentation burden is associated with recording-level false alarms.

**Implementation issue:** The first diagnostic execution emitted warnings because participant-level balanced accuracy used different class denominators when a participant lacked one or more stages. Before interpreting results, that field was replaced with fixed-five-stage macro recall using labels 0-4 and zero contribution for absent stages. The issue is preserved in the experiment record. Event, timing, fragmentation, and bootstrap definitions did not change.

**Participant result:** SF-C improved stage macro F1 for all 20 test participants. Event F1 improved for 10 and was unchanged for 10; no participant declined. False alarms/hour decreased for 11 participants and increased for nine. The paired participant bootstrap estimated an SF-C minus SF-B event-F1 difference of +0.0431, with an exploratory 95% interval from +0.0199 to +0.0676. The false-alarms/hour difference was -0.0576, with an interval from -0.5028 to +0.3445, so a consistent false-alarm reduction was not established.

**Timing result:** At the frozen +/-45-second tolerance, SF-C had 18 exact test matches, six one epoch early, and one one epoch late. The predominance of early errors is consistent with premature predicted departure from REM.

**Bout-distribution result:** In SF-C test sequences, 59.20% of predicted REM bouts lasted 30 or 60 seconds, compared with 14.10% of human REM bouts. Only 7.63% of predicted bouts exceeded 300 seconds, compared with 67.31% of human bouts.

**Association result:** Predicted REM bouts/hour had descriptive Spearman rho 0.5118 with false alarms/hour across the 26 test recordings. Predicted all-stage transitions/hour had rho 0.3983. These unadjusted exploratory correlations support, but do not prove, the fragmentation mechanism.

The SF-C convergence warning limits claims that the fitted logistic objective reached its numerical optimum. It does not explain away the observed high false-alarm rate, and it must remain visible in later comparisons. Any higher-iteration retry must be a separately versioned experiment.

Proceed to Block 6 with a direct REM-to-Wake feature baseline. The next experiment must freeze training-only negative sampling and validation threshold selection before fitting. A CNN is not justified until a simple direct baseline identifies a specific limitation that additional temporal representation could test.
