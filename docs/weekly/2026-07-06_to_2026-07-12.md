## 2. Work Completed

### 2026-07-09

#### Background-window rule test

**Hypothesis:** BOAS contains enough non-transition background windows if each candidate window excludes the 30-second uncertainty interval around every REM/Wake boundary.

**Method:** Added `scripts/build_background_windows_v0_1.py` and `docs/labels/background_window_spec_v0.1.md`. The rule treats each adjacent PSG epoch boundary as a possible background center, uses the same 240-second extraction window as the transition labels, and excludes any candidate within 135 seconds of a REM/Wake boundary. The 135-second exclusion combines the 120-second half-window and the 15-second boundary uncertainty.

**Result:** The v0.1 build found 119,967 possible adjacent-epoch centers and 115,275 eligible background centers. Of these, 83,688 were strict same-stage windows and 31,587 were non-target windows with no nearby REM/Wake boundary. A deterministic review table with 4,302 rows was written to `labels/background_windows_v0.1/`.

**Limitation:** The full eligible background pool was summarized but not written as a large Git table. The review table is not a final training set.

**Decision:** Proceed with background-window rule v0.1 for the label/preprocessing gate. Final background sampling remains blocked until split design is reviewed.

#### Quality-flag construction

**Hypothesis:** The current transition and background windows can be carried forward if critical label/mapping flags are separated from softer signal-proxy notes.

**Method:** Added `scripts/build_signal_quality_flags_v0_1.py` and `docs/labels/signal_quality_flag_spec_v0.1.md`. The artifact combines PSG label-structure checks, PSG/headband sample-mapping checks, window geometry checks, and previously computed pulse/EEG-envelope proxy summaries.

**Result:** The v0.1 quality build wrote `labels/signal_quality_flags_v0.1/`. Under the current critical checks, 128 of 128 recordings, 476 of 476 transition windows, and 4,302 of 4,302 background review windows include for preprocessing. Proxy notes were preserved but did not automatically exclude windows.

**Limitation:** These flags do not yet compute full amplitude artifact metrics from every headband channel.

**Decision:** Use quality flags v0.1 for the label/preprocessing gate. Model training remains blocked.

#### Participant-grouped split-readiness review

**Hypothesis:** A future split can be designed by `pid` without placing repeated recordings from the same participant into more than one partition.

**Method:** Added `scripts/review_grouped_split_readiness_v0_1.py`. The script summarizes transition labels, background review windows, and quality decisions by BOAS `pid`.

**Result:** The readiness review wrote `labels/split_readiness_v0.1/`. It found 100 `pid` values with reviewed windows, 88 `pid` values with primary REM-to-Wake labels, 100 `pid` values with background review windows, and 88 `pid` values with both primary positives and background windows. It also identified 20 `pid` values with repeated recordings.

**Limitation:** No train/validation/test split was assigned. The review table is evidence for split design, not a final split.

**Decision:** Keep the split policy grouped by `pid`. The next step is to define a deterministic split policy and report event/background balance before any model work.

### 2026-07-11

#### Full headband window amplitude and continuity assessment

**Hypothesis:** Most reviewed transition and background windows contain finite, non-flat signal in both `HB_1` and `HB_2`, while a smaller subset will require explicit review or exclusion before grouped split design.

**Method:** Predeclared the rules in `docs/feasibility/headband_window_signal_quality_protocol_v0.1.md`, then ran `scripts/assess_boas_headband_window_quality_v0_1.py` across all 128 headband EDF recordings. The assessment measured 9,556 channel-window combinations covering 476 transition windows and 4,302 background review windows. Critical missing, nonfinite, constant, near-flat, and at-least-five-second flatline failures were separated from review-only amplitude, jump, endpoint, and 10-MAD indicators.

**Result:** Fifteen transition windows and 20 background review windows met a critical exclusion rule. The transition exclusions were all REM-to-Wake events, leaving 350 of 365 primary events. All 88 `pid` groups that contributed a primary event still retain at least one. Critical exclusions occur in 12 `pid` groups and are concentrated in `pid 89`, `pid 77`, and `pid 91`. A further 381 windows received targeted amplitude, jump, or endpoint review flags.

**Insufficient approach:** The predeclared 10-MAD review rule was too nonspecific for raw EEG. It flagged 2,663 of 9,556 channel-window measurements and reached every participant group, so it cannot distinguish unusable windows by itself.

**Resolution:** Preserved the 10-MAD result as a sensitivity flag rather than an exclusion. Later review will prioritize amplitude-range, peak-to-peak, abrupt-jump, and repeated-endpoint flags. Critical signal failures remain excluded.

**Decision:** The E0 feasibility decision remains `proceed`. The dated closeout is recorded in `docs/feasibility/e0_feasibility_closeout_2026-07-11.md`. Block 4 must incorporate these exclusions before freezing participant splits or preprocessing.
